First Unified LALM for Audio, Speech & Music Timestamping

TEMPO: Temporally-grounded Multi-task Post-training for Large Audio-Language Models

Apoorva Kulkarni • Kaousheik Jayakumar • Sreyan Ghosh • Utathya Aich • Ramani Duraiswami • Dinesh Manocha
University of Maryland, College Park
Code Repository Hugging Face Dataset (119K) Model Checkpoints

Abstract & Overview

Large audio-language models (LALMs) describe audio at the clip level but cannot assign timestamps to the events, speakers, or sounds they identify. Despite being essential for downstream tasks like speech recognition and dense audio captioning, timestamping remains a key limitation of most LALMs.


We present TEMPO (Temporally-grounded Multi-task Post-training), the first unified model to handle audio, speech, and music timestamping tasks in a single decoder. TEMPO is trained on a synthetic-to-real post-training curriculum and refined using Group Relative Policy Optimization (GRPO) with verifiable temporal rewards.

Core Architectural Innovations

1. Atomic Timestamp Tokens

Replaces BPE subword fragmentation with ~601 dedicated discrete tokens <|0.0|> to <|60.0|> at 0.1s resolution, enabling a single softmax prediction over exact wall-clock timestamps.

2. Time-Aware Projector

Injects sinusoidal wall-clock encodings φ(t) into frozen audio encoder frame features, enabling the LLM decoder to directly perceive elapsed temporal structure spanning sub-second to long-range events.

3. Distance-Aware Gaussian Loss

Applies a Gaussian target distribution ($\sigma_t = 0.3s$) over the timestamp vocabulary to grant partial credit for near-miss predictions, matching the ordinal nature of temporal evaluation metrics (tIoU).

Methodology & 3-Stage Training

Post-Training Curriculum

TEMPO is initialized from Audio Flamingo 3 (Whisper-large encoder + Qwen2-7B LLM) and follows a progressive three-stage optimization recipe:

Stage 1: Cold Start SFT

Synthetic Calibration

51K Synthetic Samples

Establishes uniform timestamp vocabulary distribution across all tasks.

Stage 2: Real-Data SFT

Supervised Fine-Tuning

33K Real-World Samples

Fine-tunes on real conversational, sound, and music corpora.

Stage 3: RL with GRPO

Verifiable Rewards

35K Optimization Steps

Refines temporal boundaries directly against evaluation metrics (WER, mIoU, F1).

Time-Aware Projection Formula:

h_t = Linear_2( σ( Linear_1( x_t + W_τ * φ(t) ) ) )

5 Unified Timestamping Tasks

Task Tag: [speech: asr] Benchmark: AMI Meeting Corpus

Provides timestamped transcriptions for multi-speaker conversational audio.

[speech: asr] <|0.0|> The memory uh <|2.2|> Pops up the options <|4.5|> [speech: asr] <|4.9|> Yeah yeah that would be possible <|7.1|>
Task Tag: [speech: diar] Benchmark: AMI Meeting Corpus

Identifies speaker turns and active speaker time spans.

[speech: diar] <|0.0|> Speaker 1 <|6.2|> [speech: diar] <|4.6|> Speaker 2 <|6.1|> [speech: diar] <|5.9|> Speaker 3 <|6.9|>
Task Tag: [audio:ground] Benchmark: AudioSet Strong / TACOS

Localizes specific textual sound queries to temporal start and end intervals.

Query: "a bird tweets quietly outdoors"
[audio:ground] <|0.9|> to <|1.4|> [audio:ground] <|2.3|> to <|2.8|>
Task Tag: [audio:caption] Benchmark: TACOS Benchmark

Segments audio stream and provides natural language captions for each sound event.

[audio:caption] <|0.0|> A river flows loudly outdoors. <|23.9|> [audio:caption] <|0.9|> A bird tweets quietly. <|1.4|>
Task Tag: [audio:music] Benchmark: Slakh2100 Benchmark

Generates structured chord progressions, instrument entries/exits, tempo BPM, and note stats.

[audio:music] [instrument] Organ enters at <|0.0|> exits at <|30.0|> [tempo] 120.0 BPM at <|0.0|> [chord] B:min from <|0.0|> to <|3.5|> [chord] D:sus2 from <|3.5|> to <|21.0|>
